# Shanmukha Readymades
1. Supabase: new project, run `supabase.sql` once in SQL Editor.
2. Authentication > Users > Add user (tick Auto Confirm). Then run the commented `insert into admins` line with your email.
3. Copy `.env.example` to `.env`; paste Project URL (no trailing path) and the publishable key. Never use the secret key.
4. `npm install && npm run dev`
5. GitHub: `git init && git add . && git commit -m init && git branch -M main && git remote add origin <repo-url> && git push -u origin main`
6. Vercel: import repo, add the 3 env variables, Deploy.
Admin: Contact page, press and hold "Send message" for 3 seconds.
